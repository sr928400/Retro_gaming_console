# Retro Gaming Console
## Github Repo:
https://github.com/sr928400/Retro_gaming_console.git
### This project creates an XMLHttpRequest and uses open() to set up a GET request to the API url. It uses send() to send requests and checks status returning a status code number. If it works properly it uses JSON to turn response to javascript. This project loops through the console data to find the oldest and newests consoles.  Then it displays the information on the newest and oldest consoles in a summary.
